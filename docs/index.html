How this board works
  • Anyone can read the board. Sign in with your email to post, pray along, or see contact details.
  • A moderator reviews every post before it appears. If something looks wrong, use “Report” on the post.
  • Please ask before sharing someone else’s prayer request or personal situation.
  • Tradespeople list themselves. The church does not vet, license or guarantee their work, so ask for references and get estimates in writing.
  • When a prayer is answered or a need is met, mark it so others can rejoice with you.
