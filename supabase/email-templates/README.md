# Account email templates

Copies of the emails Supabase sends for accounts. They live in Supabase under
Authentication -> Emails -> Templates; these files are a backup and a reference.
Supabase fills in {{ .ConfirmationURL }} with the real link.

| Supabase template | File | Subject |
|---|---|---|
| Confirm signup | confirm-signup.html | Confirm your email for the "One Another" Board |
| Magic link | magic-link.html | Your sign-in link for the "One Another" Board |
| Reset password | reset-password.html | Reset your "One Another" Board password |
